Vector Health

Библиотека медицинских и биомедицинских навыков: 1541 навык из четырёх открытых коллекций плюс три собственных. Единая структура skills/<имя>/SKILL.md, каталог для поиска и карта происхождения по каждому навыку.

Не программа и не медицинское изделие. Навыки описывают методики — как считать мета-анализ, как читать DICOM локальной моделью, как оценить риск смещения; клиническое решение остаётся за специалистом.

Как это работает

Четыре апстрима ──┐
OpenClaw  777     │
AIPOCH    600     ├─→ sync_upstreams.py ─→ skills/ (1541) ─→ агент читает по запросу
openmed    74     │   идемпотентна:           │
Aperivue   59     │   повторный запуск = 0    ├─→ build_index.py ─→ skills-index.json
                  │                           │
собственные 2 ────┘                           └─→ validate.py ─→ CI: числа, лицензии, ссылки
Идемпотентная синхронизацияСравнение с HEAD апстрима: повторный запуск даёт нуль изменений — это и есть проверка, что синхронизация завершена.
Файлы-ссылки из форковУ части навыков SKILL.md из одного источника, а references/ — из другого, более полного форка.
Битые ссылки под учётом483 ссылки ведут на файлы, которых нет ни у одного источника (лежали в отрезанных tests/). Инвентарь с причиной по каждой.

Быстрый старт

git clone https://github.com/Osmosy/vector-health.git
cd vector-health

# найти навык по каталогу
python3 -c "
import json
for s in json.load(open('skills-index.json'))['skills']:
    if 'dicom' in s['name']: print(s['path'], '—', s['description'][:80])
"

# прочитать методику и подключить к агенту
less skills/dicom-vlm-analysis/SKILL.md
cp -r skills/dicom-vlm-analysis ~/.hermes/skills/

# проверить целостность
python3 scripts/validate.py

Ограничения лицензий

MIT репозитория покрывает собственный вклад. Внутри библиотеки есть навыки, которые считать свободными нельзя, и это зафиксировано явно:

ЧтоНавыковСледствие
Проприетарная шапка в тексте («All Rights Reserved», © MD BABU MIA — из апстрима OpenClaw)308считать MIT нельзя; текст запрещает копирование
Офисные навыки Anthropic (xlsx, pdf, docx, pptx, PPTX-Skill и -official)9нужен ваш договор с Anthropic
Non-Commercial2коммерческое использование запрещено
Это свойство источников, а не сборки: OpenClaw заявляет MIT в README, держа проприетарную шапку в 280 своих навыках. Чужие лицензионные тексты мы не переписываем — фиксируем факт, чтобы риск был виден до использования.
