# Atrial Fibrillation Treatment

## When to Use
- «Как лечить / устранить фибрилляцию предсердий?»
- Выбор ритм-контроль vs контроль ЧСС, аблация vs препараты, схема антикоагуляции.
- Нужен современный (ESC 2024+) доказательный подход.

## Classification (определяет метод)
- **Пароксизмальная** — приступы <7 дней, часто самокупируются.
- **Персистирующая** — >7 дней, нужна кардиоверсия.
- **Длительно персистирующая** — >1 года непрерывно.
- **Постоянная (permanent)** — ритм не восстанавливаем: ЧСС-контроль + антикоагуляция.

## Framework: ESC 2024 «AF-CARE»
- **C** — Comorbidities/факторы риска: вес, алкоголь, апноэ, АД, физнагрузка (обязательный компонент).
- **A** — Avoid stroke: антикоагуляция по CHA₂DS₂-VA.
- **R** — Rate & rhythm control.
- **E** — Evaluation: динамическая переоценка.

## Rhythm control: метод по профилю

| Форма / профиль | Первая линия | Дальше |
|---|---|---|
| Пароксизмальная, нет структурной болезни | Аблация (PFA/крио) first-line; «таблетка в кармане» | Антиаритмик постоянно |
| Пароксизмальная, эпизодическая | Pill-in-the-pocket (флекаинид/пропафенон) | Аблация |
| Персистирующая (первый год) | Ранний ритм-контроль (EAST-AFNET 4) | Расширенная аблация |
| Персистирующая + СНнФВ | Аблация (CASTLE-AF / CASTLE-HTx) | — |
| Длительно персистирующая | Расширенная аблация / гибрид / Cox-Maze | Rate control |
| Пожилые, бессимптомные, постоянная | Rate control (β-блокатор/дилтиазем/дигоксин) + АК | — |

## Antiarrhythmics — строго по структурной болезни сердца
- **Без структурной болезни**: флекаинид, пропафенон (класс IC), соталол, дронедарон.
- **ИБС / гипертрофия ЛЖ / ХСН**: IC класс ПРОТИВОПОКАЗАН (проаритмия) → амиодарон, дофетилид; соталол осторожно.
- Амиодарон — самый эффективный, самый токсичный (щитовидная железа, лёгкие, печень, кожа).

## Ablation technologies

| Технология | Механизм | Плюсы | Минусы |
|---|---|---|---|
| PFA (pulsed field) | Электропорация, не термическая | Селективна к кардиомиоцитам, щадит пищевод/диафрагмальный нерв; быстрее | Молодая технология |
| Криобаллон | Заморозка | Воспроизводимость, круговая изоляция одним баллоном | Пищевод, диафрагмальный нерв |
| RF (радиочастотная) | Нагрев | Управляемая геометрия, расширенные схемы | Дольше; HP-SD снижает риски |

Эффективность PVI ~70–80% (пароксизмальная, одна процедура); при персистирующей ниже.

## Anticoagulation (ось A)
- **CHA₂DS₂-VA** (ESC 2024, пол убран из счёта): ХСН 1, АГ 1, возраст ≥75 = 2, диабет 1, инсульт/ТИА/ТЭ = 2, сосудистая патология 1, возраст 65–74 = 1.
- **≥2 → антикоагулянт**: DOAC (апиксабан, ривароксабан, дабигатран, эдоксабан); варфарин — при мех. клапанах / тяжёлом митральном стенозе.
- **LAAO** (Watchman FLX, Amplatzer Amulet) — при противопоказаниях к антикоагуляции.

## Key trials

| Триал | Вопрос | Результат |
|---|---|---|
| EAST-AFNET 4 (2020) | ранний ритм-контроль vs обычная тактика | лучше (HR 0.79) |
| EARLY-AF (2022) | крио-аблация first-line vs препараты | лучше (рецидив 32% vs 57%) |
| STOP-AF First (2021) | то же | 74.6% vs 45% |
| CASTLE-AF (2018) / CASTLE-HTx (2023) | аблация при ФП+СН | ниже смертность/госпитализации |
| ADVENT (2023) | PFA vs термическая | не хуже, быстрее, безопаснее |
| AFFIRM (2002, исторический) | rate vs rhythm | без разницы (до эпохи аблации) |

## Pitfalls
- AFFIRM («rate = rhythm») устарел для ранней ФП — EAST-AFNET 4 его переопределил.
- IC класс противопоказан при структурной болезни сердца.
- Мониторить токсичность амиодарона (ТТГ, АЛТ/АСТ, рентген лёгких).
- Успех аблации ~70–80% пароксизмальная, ниже персистирующая — честно доносить пациенту.
- Антикоагуляция нужна независимо от стратегии ритма (по CHA₂DS₂-VA).

## Summary
Пароксизмальная без СБС → PFA/крио first-line; персистирующая первый год → ранний ритм-контроль;
ФП+СН → аблация; пожилые бессимптомные постоянная → rate control; всем — антикоагуляция
по CHA₂DS₂-VA ≥2 + факторы риска (вес/алкоголь/апноэ/АД).
