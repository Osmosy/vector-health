# Atrial Fibrillation Treatment

> **Для специалиста, не для самолечения.** Навык описывает тактику по опубликованным
> рекомендациям; он не является назначением и не заменяет клиническое решение.
> Дозы, пороги и выбор метода проверяются по актуальной версии рекомендаций и с учётом
> индивидуальных противопоказаний. Версии рекомендаций и даты указаны в `## References`;
> при расхождении текста навыка с первоисточником приоритет у первоисточника.

## When to Use
- «Как лечить / устранить фибрилляцию предсердий?»
- Выбор ритм-контроль vs контроль ЧСС, аблация vs препараты, схема антикоагуляции.
- Нужен современный (ESC 2024+) доказательный подход.

## Classification (определяет метод)
- **Пароксизмальная** — приступы <7 дней, часто самокупируются.
- **Персистирующая** — >7 дней, нужна кардиоверсия.
- **Длительно персистирующая** — >1 года непрерывно.
- **Постоянная (permanent)** — ритм не восстанавливаем: ЧСС-контроль + антикоагуляция.

## Framework: ESC 2024 «AF-CARE»
- **C** — Comorbidities/факторы риска: вес, алкоголь, апноэ, АД, физнагрузка (обязательный компонент).
- **A** — Avoid stroke: антикоагуляция по CHA₂DS₂-VA.
- **R** — Rate & rhythm control.
- **E** — Evaluation: динамическая переоценка.

## Rhythm control: метод по профилю

| Форма / профиль | Первая линия | Дальше |
|---|---|---|
| Пароксизмальная, нет структурной болезни | Аблация (PFA/крио) first-line; «таблетка в кармане» | Антиаритмик постоянно |
| Пароксизмальная, эпизодическая | Pill-in-the-pocket (флекаинид/пропафенон) | Аблация |
| Персистирующая (первый год) | Ранний ритм-контроль (EAST-AFNET 4) | Расширенная аблация |
| Персистирующая + СНнФВ | Аблация (CASTLE-AF / CASTLE-HTx) | — |
| Длительно персистирующая | Расширенная аблация / гибрид / Cox-Maze | Rate control |
| Пожилые, бессимптомные, постоянная | Rate control (β-блокатор/дилтиазем/дигоксин) + АК | — |

## Antiarrhythmics — строго по структурной болезни сердца
- **Без структурной болезни**: флекаинид, пропафенон (класс IC), соталол, дронедарон.
- **ИБС / гипертрофия ЛЖ / ХСН**: IC класс ПРОТИВОПОКАЗАН (проаритмия) → амиодарон, дофетилид; соталол осторожно.
- Амиодарон — самый эффективный, самый токсичный (щитовидная железа, лёгкие, печень, кожа).

## Ablation technologies

| Технология | Механизм | Плюсы | Минусы |
|---|---|---|---|
| PFA (pulsed field) | Электропорация, не термическая | Селективна к кардиомиоцитам, щадит пищевод/диафрагмальный нерв; быстрее | Молодая технология |
| Криобаллон | Заморозка | Воспроизводимость, круговая изоляция одним баллоном | Пищевод, диафрагмальный нерв |
| RF (радиочастотная) | Нагрев | Управляемая геометрия, расширенные схемы | Дольше; HP-SD снижает риски |

Эффективность PVI ~70–80% (пароксизмальная, одна процедура); при персистирующей ниже.

## Anticoagulation (ось A)
- **CHA₂DS₂-VA** (ESC 2024, пол убран из счёта): ХСН 1, АГ 1, возраст ≥75 = 2, диабет 1, инсульт/ТИА/ТЭ = 2, сосудистая патология 1, возраст 65–74 = 1.
- **≥2 → антикоагулянт**: DOAC (апиксабан, ривароксабан, дабигатран, эдоксабан); варфарин — при мех. клапанах / тяжёлом митральном стенозе.
- **LAAO** (Watchman FLX, Amplatzer Amulet) — при противопоказаниях к антикоагуляции.

## Key trials

Все семь сверены по первоисточнику (Europe PMC, PMID в таблице). Год, том и цифры
берутся из записи журнала, а не из вторичных обзоров.

| Триал | Вопрос | Результат (первичная точка) |
|---|---|---|
| EAST-AFNET 4 (NEJM 2020;383(14):1305–1316, PMID 32865375) | ранний ритм-контроль vs обычная тактика | лучше: 3.9 vs 5.0 события на 100 пациенто-лет, **HR 0.79** (96% ДИ 0.66–0.94) |
| EARLY-AF (NEJM 2021;384(4):305–315, PMID 33197159) | криоаблация first-line vs антиаритмики | рецидив за 1 год **42.9% vs 67.8%**, HR 0.48 (95% ДИ 0.35–0.66) |
| STOP-AF First (NEJM 2021;384(4):316–324, PMID 33197158) | то же, криобаллон как начальная терапия | успех за 12 мес **74.6% vs 45.0%** (95% ДИ 65.0–82.0 и 34.6–54.7) |
| CASTLE-AF (NEJM 2018;378(5):417–427, PMID 29385358) | аблация при ФП+СНнФВ | 28.5% vs 44.6% событий, **HR 0.62**; смертность 13.4% vs 25.0% |
| CASTLE-HTx (NEJM 2023;389(15):1380–1389, PMID 37634135) | аблация при терминальной СН | остановлен досрочно по эффективности: **8% vs 30%** событий, HR 0.24 (95% ДИ 0.11–0.52) |
| ADVENT (NEJM 2023;389(18):1660–1671, PMID 37634148) | PFA vs термическая аблация | не хуже: эффективность **73.3% vs 71.3%** (equivalence), короче процедура |
| AFFIRM (NEJM 2002;347(23):1825–1833, PMID 12466506) | rate vs rhythm (исторический) | без разницы по смертности (4060 пациентов, до эпохи аблации) |

Внимание на пару EARLY-AF (PMID 33197159) / STOP-AF First (PMID 33197158): оба — NEJM
2021;384(4), соседние работы (305–315 и 316–324), и первичные точки у них разные по
построению — у EARLY-AF это рецидив (чем меньше, тем лучше), у STOP-AF First — успех
лечения (чем больше, тем лучше). Переносить цифры из одной в другую нельзя: 42.9%
рецидива и 74.6% успеха — цифры из разных работ.

## Pitfalls
- AFFIRM («rate = rhythm») устарел для ранней ФП — EAST-AFNET 4 его переопределил.
- IC класс противопоказан при структурной болезни сердца.
- Мониторить токсичность амиодарона (ТТГ, АЛТ/АСТ, рентген лёгких).
- Успех аблации ~70–80% пароксизмальная, ниже персистирующая — честно доносить пациенту.
- Антикоагуляция нужна независимо от стратегии ритма (по CHA₂DS₂-VA).

## Summary
Пароксизмальная без СБС → PFA/крио first-line; персистирующая первый год → ранний ритм-контроль;
ФП+СН → аблация; пожилые бессимптомные постоянная → rate control; всем — антикоагуляция
по CHA₂DS₂-VA ≥2 + факторы риска (вес/алкоголь/апноэ/АД).

Все семь — записи типа Randomized Controlled Trial (ADVENT — Equivalence Trial),
проверено по списку типов публикации в записи. Машиночитаемая копия этих данных:
`docs/trials-verified.json`.

Как это сверялось и почему таблица выглядит так: раньше в навыке стояли годы и цифры
по памяти, и они разошлись с первоисточником — так, `EARLY-AF` был указан как 2022 с
рецидивом «32% vs 57%», хотя это NEJM 2021 (PMID 33197159) с **42.9% vs 67.8%**;
у `EAST-AFNET 4` страницы оканчивались 1313 вместо 1316. Первый же запрос к PubMed
закрыт проверкой на робота, поэтому сверка шла через Europe PMC (открытый API того же
индекса): поиск по названию и автору, затем чтение записи по PMID — журнал, год, том,
страницы, типы публикации и цифра первичной точки из аннотации.

Отдельная ловушка, из-за которой сверка обязана идти по типу публикации: у `CASTLE-AF`
под тем же названием есть запись-письмо в редакцию (PMID 30067924, NEJM 2018;379(5):492) —
две строки, различие только в типе и номерах страниц. Ссылка на письмо вместо
исследования выглядит как ссылка на доказательство, которого нет.

**Что делать перед применением:** версия рекомендаций ESC проверяется отдельно (2024 —
AF-CARE, CHA₂DS₂-VA без учёта пола), а выходные данные испытаний — по PMID выше.

## Guardrails

- Навык не выдаёт назначения: только тактика по рекомендациям с явной версией.
- Дозировки и пороги всегда сверяются с актуальной версией рекомендаций.
- При расхождении с первоисточником приоритет — у первоисточника, а расхождение
  фиксируется как дефект навыка.
